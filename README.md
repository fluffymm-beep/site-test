# گالری پرامپت ChatGPT

یک پروژه‌ی ساده جنگو برای نمایش مجموعه‌ای از پرامپت‌های ساختاریافته به زبان فارسی.

## اجرای پروژه

1. ایجاد و فعال‌سازی محیط مجازی:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
2. نصب وابستگی‌ها:
   ```bash
   pip install -r requirements.txt
   ```
3. اعمال مایگریشن‌ها و راه‌اندازی پایگاه داده:
   ```bash
   python manage.py migrate
   ```
   این مرحله دسته‌ها و پرامپت‌های اولیه را نیز بارگذاری می‌کند.
4. ایجاد کاربر مدیر برای ورود به پنل ادمین (اختیاری اما توصیه‌شده):
   ```bash
   python manage.py createsuperuser
   ```
5. اجرای سرور توسعه:
   ```bash
   python manage.py runserver
   ```

سپس در مرورگر آدرس [http://localhost:8000](http://localhost:8000) را باز کنید تا گالری پرامپت‌ها و امکان جستجوی آن‌ها را مشاهده کنید. برای مدیریت محتوا نیز از مسیر [http://localhost:8000/admin/](http://localhost:8000/admin/) وارد پنل ادمین شوید.

## امکانات

- رابط کاربری شیشه‌ای (Glassmorphism) با پالت Midnight Blue و Neon Cyan.
- جستجوی زنده‌ی پرامپت‌ها بر اساس عنوان و متن.
- مدیریت دسته‌ها و پرامپت‌ها از طریق پنل ادمین جنگو.
- نکات سریع برای نوشتن پرامپت در انتهای صفحه.

## ساختار

- `promptgallery/` تنظیمات اصلی پروژه
- `prompts/` اپلیکیشن حاوی مدل‌ها، نما و ثبت در ادمین
- `templates/` قالب‌های HTML برای لایه‌بندی و نمایش گالری
